## デザイン原則

### 1. 透明性ファースト（Transparency First）

> 「91%のドナーが透明性のある組織を支援したいと回答」

- 手数料は事前に明確に表示
- 寄付金の使途をリアルタイムで可視化
- 隠れたコストは一切なし

### 2. 最小摩擦（Minimum Friction）

> 「18%のカート放棄は複雑なフォームが原因」

- 入力項目は必要最小限
- ワンクリックで完了できる操作を目指す
- ゲストチェックアウト対応

### 3. 包括的アクセシビリティ（Inclusive Accessibility）

> 「日本の高齢化率は29.1%」

- 高齢者・障害者にも使いやすいデザイン
- キーボード操作完全対応
- スクリーンリーダー対応

### 4. 信頼の構築（Trust Building）

> 「正直なコミュニケーションでドナー維持率22%向上」

- セキュリティの可視化
- 進捗の透明な共有
- 迅速なサポート対応

**課題**: フォームの長さが見えず離脱（離脱率60〜70%）

```
│  │   寄付金額を選択してください                │   │
│  │                                             │   │
│  │   ┌───────┐  ┌───────┐  ┌───────┐          │   │
│  │   │ ¥500  │  │¥1,000 │  │¥3,000 │          │   │
│  │   └───────┘  └───────┘  └───────┘          │   │
│  │                                             │   │
│  │   ┌───────┐  ┌───────┐  ┌───────────────┐  │   │
│  │   │¥5,000 │  │¥10,000│  │  その他 ¥     │  │   │
│  │   └───────┘  └───────┘  └───────────────┘  │   │

│  │   ☐ 毎月寄付する（月額）                    │   │
```

**実装ポイント**:
- ステップ数は3以下に抑える
- 現在のステップを視覚的に強調
- 残り時間の目安を表示（「約1分」）
- 「戻る」ボタンも用意

**課題**: 手数料が不透明で不信感（「高い」という声多数）

```
│                                                     │
│   ┌─────────────────────────────────────────────┐   │

│   │     す。運営費は別の方法で賄っています。    │   │
│   └─────────────────────────────────────────────┘   │
│                                                     │
│   ☐ 手数料も負担する（+¥360）                     │
│      → ¥10,000がそのまま届きます                  │
│                                                     │
└─────────────────────────────────────────────────────┘
```

**実装ポイント**:
- 金額入力と連動してリアルタイム計算
- 手数料の内訳を明示
- 手数料負担オプションを提供
- 「なぜ手数料がかかるか」の説明リンク
