## embed-widget.spec.md の変更

### 1. ステップ表示フォーム（NEW）

**変更内容**: 寄付フォームを3ステップに分割し、進捗表示を追加

```
① 金額選択 ─── ② 情報入力 ─── ③ 完了
     ●              ○              ○
「あと約1分で完了します」
```

**理由**:
- 調査: 未対策フォームの離脱率は60-70%
- ステップ表示で**完了率+55%**向上（Kaizen Platform事例）
- 残り時間目安が心理的ハードルを下げる

**矛盾チェック**: 既存のURL構成・決済フローに影響なし。UIのみの変更。

---

### 2. 金額ボタンにインパクトメッセージ（MODIFIED）

**変更内容**: 金額選択ボタンに寄付の効果を記載

```
┌─────────────────────────────────────────────┐
│         ¥1,000           ★ 人気             │
│   📚 学用品1セット分                        │
└─────────────────────────────────────────────┘
```

**理由**:
- 調査: インパクト可視化で寄付額・意欲が向上
- Seed Savers Exchange事例: 平均寄付額が$112→$181に増加

**矛盾チェック**: 既存のpriceOptionsスキーマにimpact/labelフィールドを追加することで対応可能。

---

### 3. 手数料透明表示（NEW）

**変更内容**: リアルタイムで手数料と実際に届く金額を表示

```
寄付金額          ¥1,000
決済手数料(3.6%)   - ¥36
実際に届く金額     ¥964

☐ 手数料も負担する（+¥36）
```

**理由**:
- 調査: **91%**のドナーが透明性を重視
- 競合（CAMPFIRE等）への不満で「手数料が不透明」が多数

**矛盾チェック**: 既存の手数料計算ロジック（3.6%）と整合。UIのみの追加。

---

### 4. デジタルウォレット優先表示（MODIFIED）

**変更内容**: Apple Pay / Google Pay を決済方法の最上部に配置

```
┌─────────────────────────────────────────────┐
│       Apple Pay で ¥1,000 を寄付           │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│       Google Pay で ¥1,000 を寄付          │
└─────────────────────────────────────────────┘

────────────── または ──────────────

💳 クレジットカード / 📱 PayPay / 🏦 銀行振込
```

**理由**:
- 調査: デジタルウォレットは**4倍高速**にチェックアウト完了
- モバイルユーザーの57%がスマホで決済（2024年）

**矛盾チェック**: 既存の決済方法（card, paypay, bank_transfer）に影響なし。表示順序のみ変更。

---

### 5. セキュリティバッジ表示（NEW）

**変更内容**: 決済画面にセキュリティバッジを表示

```
🔒 SSL暗号化 │ 💳 Stripe │ ✅ PCI DSS準拠
カード情報は当サイトには保存されません
```

**理由**:
- 調査: 信頼性表示がコンバージョン率向上に寄与
- GoFundMe/Patreonへの不満で「信頼できない」という声

**矛盾チェック**: 既存のセキュリティ実装（Stripe連携）の事実を表示するのみ。

---

### 6. インラインバリデーション（NEW）

**変更内容**: 入力中にリアルタイムでフィードバック表示

```
メールアドレス *
┌─────────────────────────────────────────────┐
│ user@example.com                        ✅  │
└─────────────────────────────────────────────┘
```

**理由**:
- 調査: 送信後エラーで離脱率増加
- インラインバリデーションで**フォーム放棄率14%減**（Baymard Institute）

**矛盾チェック**: 既存のZodバリデーションルールをフロントエンドでも適用。

---

### 7. 完了画面インパクトメッセージ（MODIFIED）

**変更内容**: 完了画面に寄付の効果を具体的に表示

```
🎯 この寄付で
   子ども1人に学用品1セットを
   届けることができます
```

**理由**:
- 調査: ドナー満足度向上でリピート率増加
- Charity:Water成功事例から

**矛盾チェック**: 既存の完了画面構造を拡張。

---

### 8. アクセシビリティ詳細仕様（ENHANCED）

**変更内容**: 具体的な数値基準を追加

| 項目 | 基準 | 理由 |
|------|------|------|
| フォントサイズ | 最小16px | ズーム防止、可読性 |
| タップターゲット | 最小48x48px | 高齢者の操作性 |
| ボタン間隔 | 最小8px | 誤タップ防止 |
| コントラスト比 | 4.5:1以上 | 視覚障害対応 |

**理由**:
- 日本の高齢化率**29.1%**（2023年）
- 障害者差別解消法改正（2024年4月）で合理的配慮義務化

**矛盾チェック**: 既存の「アクセシビリティ」記載を具体化したのみ。

## admin.spec.md の変更

### 9. super_admin権限追加（NEW）

**変更内容**: 3階層目の権限レベルを追加

| 機能 | viewer | editor | super_admin |
|------|--------|--------|-------------|
| システム設定変更 | × | × | ○ |
| 監査ログ閲覧 | × | × | ○ |
| super_admin作成 | × | × | ○ |

**理由**:
- セキュリティレビューで「最上位権限」の必要性が指摘
- 既存コードで既に`super_admin`が`AdminRole`型に追加済み

**矛盾チェック**: 既存のviewer/editor権限に影響なし。上位互換。

---

### 10. 寄付者セルフサービスポータル（NEW）

**変更内容**: 寄付者が自分でサブスクを管理できるページを追加

**URL**: `/my/subscriptions?token=<email_link_token>`

機能:
- 金額変更
- 一時停止（最大3ヶ月）
- ワンクリックキャンセル
- 寄付履歴ダウンロード（確定申告用）

**理由**:
- FTC「Click to Cancel」規制（2024年）で**登録と同じ方法でキャンセル可能**が義務化
- 調査: キャンセル困難への不満がGoFundMe/Patreonで多数

**矛盾チェック**: 既存の`/api/subscriptions/:id/cancel`エンドポイントを活用。

---

### 11. 管理画面アクセシビリティ（NEW）

**変更内容**: 管理画面にもアクセシビリティ基準を適用

| 項目 | 基準 |
|------|------|
| フォントサイズ | 最小14px |
| タップターゲット | 最小44x44px |
| アイコン | テキストラベル併記 |

**理由**:
- 管理者にも高齢者・視覚障害者がいる可能性
- 研究: 「ハンバーガーメニュー」等のアイコンは理解されにくい

**矛盾チェック**: 既存UIに影響なし。CSS変更のみで対応可能。

---

### 12. ハンバーガーメニュー改善（MODIFIED）

**変更内容**: アイコンにテキストラベルを併記

```
変更前: ☰
変更後: ☰ メニュー
```

**理由**:
- 調査: 高齢者・ITリテラシー低い層はアイコンのみでは意味を理解できない

**矛盾チェック**: 既存のレスポンシブ対応を拡張。

---

### 13. 使途報告機能（NEW）

**変更内容**: 寄付金の使途を設定・公開する機能を追加

```
┌─────────────────────────────────────────────┐
│ カテゴリ名       │ 割合   │ アイコン      │
├───────────────────┼────────┼───────────────┤
│ 教育支援         │ 60%    │ 📚           │
│ 住居支援         │ 25%    │ 🏠           │
│ 食料支援         │ 10%    │ 🍙           │
│ 運営費           │ 5%     │ ⚙️           │
└─────────────────────────────────────────────┘
```

**理由**:
- 調査: **91%**のドナーが透明性を重視
- Charity:Water成功事例: 100%プロジェクト直接使用で**$500M+**調達

**矛盾チェック**: 新規機能。既存のsettingsテーブルにカラム追加で対応可能。

## 未変更（矛盾回避）

以下は既存仕様と矛盾するため変更しなかった:

1. **決済手数料率**: 3.6%（card/paypay）、1.5%（bank_transfer）は変更なし
2. **返金ポリシー**: 7日以内のサブスク返金ルールは維持
3. **認証フロー**: IP制限、レート制限は既存のまま
4. **Webhook処理**: Stripeイベント処理は変更なし
