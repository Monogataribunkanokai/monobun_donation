# Tasks Command

Break down a planned feature into actionable tasks.

## Instructions

1. Read the spec file from `.specify/specs/[feature-name].spec.md`
2. Read the plan file from `.specify/specs/[feature-name].plan.md`
3. Read the tasks template from `.specify/templates/tasks-template.md`
4. Create a tasks file in `.specify/specs/[feature-name].tasks.md`

## Key Principles

- **Small, focused tasks**: Each task should be completable in one step
- **Test-first tasks**: Write tests before implementation
- **Clear verification**: Each task has a way to verify completion
- **Sequential order**: Tasks should be in logical order

## Output Format

Create a tasks file with:
1. Prerequisites checklist
2. Numbered implementation tasks
3. Testing tasks
4. Verification checklist
