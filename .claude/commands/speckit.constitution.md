# Constitution Command

View or update the project constitution.

## Instructions

1. Read the current constitution from `.specify/memory/constitution.md`
2. Display the constitution to the user
3. If the user wants to update it, make the requested changes

## Constitution Contents

The constitution defines:
- Project overview
- Core development principles
- Technology stack
- Development workflow
- Code standards

## Usage

- View constitution: Just run this command
- Update: Say what you want to change
