# Accessibility Design Skill

アクセシビリティ対応（WCAG 2.1 AA準拠）を実装するスキル。

## 適用タイミング

- UI/フォーム作成時
- 高齢者対応が必要な場合
- スクリーンリーダー対応時

## 必須要件

### 視覚

| 項目 | 基準 |
|-----|------|
| フォントサイズ | 最小16px |
| コントラスト比 | 4.5:1以上 |
| タップターゲット | 最小48x48px |
| ボタン間隔 | 最小8px |

### アイコン+テキスト

```tsx
// ❌ 悪い例
<button>☰</button>

// ✅ 良い例
<button>
  <Icon name="menu" />
  <span>メニュー</span>
</button>
```

### フォーカス表示

```css
:focus {
  outline: 2px solid #2563EB;
  outline-offset: 2px;
}
```

### 文字サイズ切替

```tsx
<FontSizeToggle sizes={['小', '中', '大']} />
```

### 電話サポート表示

```tsx
<SupportInfo>
  ❓ 操作方法がわからない場合
  📞 0120-XXX-XXX（通話無料）
</SupportInfo>
```

## キーボード操作

- すべての機能がキーボードで操作可能
- Tab順序が論理的
- フォーカストラップ（モーダル内）

## 横スワイプ禁止

高齢者は横スワイプに不慣れ → 縦スクロールのみ使用

## 背景

- 日本の高齢化率: 29.1%（2023年）
- 障害者差別解消法改正（2024年4月）で合理的配慮義務化
