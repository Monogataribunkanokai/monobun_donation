# Feature Specification: 埋め込みWidget & 寄付ページ

## Overview

WordPress等の外部サイトに埋め込み可能な寄付フォーム、およびQRコード用の独立した寄付ページ。

## URL構成

| URL | 用途 |
|-----|------|
| `/donate/:eventId` | 独立した寄付ページ（QRコード用） |
| `/embed/:eventId` | iframe埋め込み用 |
| `/qr/:eventId.png` | QRコード画像 |

## 埋め込みWidget `/embed/:eventId`

### 埋め込み方法

```html
<!-- iframe埋め込み -->
<iframe
  src="https://donate.example.com/embed/summer-2025"
  width="400"
  height="600"
  style="border: none; border-radius: 8px;"
  allow="payment"
></iframe>
```

### カスタマイズパラメータ

| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| `theme` | `light` / `dark` | `light` |
| `primaryColor` | ボタン色 | `#FF5500` |
| `bgColor` | 背景色 | `#FFFFFF` |
| `bgImage` | 背景画像URL | なし |
| `fontFamily` | フォント | `sans-serif` |
| `borderRadius` | 角丸 | `8px` |
| `hideProgress` | 進捗非表示 | `false` |
| `hideMessage` | メッセージ欄非表示 | `false` |

### 使用例

```html
<!-- ダークテーマ、カスタムカラー -->
<iframe
  src="https://donate.example.com/embed/summer-2025?theme=dark&primaryColor=%23FF0000"
  width="400"
  height="600"
></iframe>

<!-- 背景画像付き -->
<iframe
  src="https://donate.example.com/embed/summer-2025?bgImage=https%3A%2F%2Fexample.com%2Fbg.jpg"
  width="100%"
  height="700"
></iframe>
```

## QRコード `/qr/:eventId.png`

### 仕様

- 形式: PNG
- サイズ: 300x300px（デフォルト）
- 内容: `https://donate.example.com/donate/:eventId`

### パラメータ

| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| `size` | 画像サイズ | `300` |
| `format` | `png` / `svg` | `png` |

### 使用例

```
/qr/summer-2025.png
/qr/summer-2025.png?size=500
/qr/summer-2025.svg
```

## セキュリティ

### iframe制限

```http
# レスポンスヘッダー
X-Frame-Options: ALLOW-FROM https://example.com
Content-Security-Policy: frame-ancestors 'self' https://example.com https://wordpress.example.com
```

設定で許可ドメインを指定。

### クロスオリジン

- 決済はStripe Checkoutにリダイレクト（同一オリジン問題なし）
- APIはCORSで許可ドメインのみ許可

## バリデーション（NEW）

インラインリアルタイム検証で離脱を防止（調査: 送信後エラーで離脱増加）。

### 入力中フィードバック

```
メールアドレス *
┌─────────────────────────────────────────────┐
│ user@example.com                        ✅  │  ← 有効時
└─────────────────────────────────────────────┘

メールアドレス *
┌─────────────────────────────────────────────┐
│ user@example                            ⚠️  │  ← 入力中
└─────────────────────────────────────────────┘
⚠️ 有効なメールアドレスを入力してください

金額
┌─────────────────────────────────────────────┐
│ 50                                      ❌  │  ← エラー
└─────────────────────────────────────────────┘
❌ 最低寄付金額は100円です
```

### バリデーションルール

| フィールド | ルール |
|-----------|--------|
| 金額 | 100円以上、10,000,000円以下、整数 |
| メール | RFC 5322準拠、最大255文字 |
| 名前 | 最大100文字（任意） |
| メッセージ | 最大1000文字（任意） |

## アクセシビリティ（WCAG 2.1 AA準拠）

日本の高齢化率29.1%を考慮し、包括的なアクセシビリティ対応を実装。

### 必須要件

| 項目 | 基準 | 理由 |
|------|------|------|
| フォントサイズ | 最小16px | ズーム防止、可読性 |
| タップターゲット | 最小48x48px | 高齢者の操作性 |
| ボタン間隔 | 最小8px | 誤タップ防止 |
| コントラスト比 | 4.5:1以上 | 視覚障害対応 |
| 入力欄高さ | 48px | タッチ操作性 |

### キーボード操作

- Tab順序が論理的（上→下、左→右）
- フォーカス表示: `outline: 2px solid #2563EB; outline-offset: 2px;`
- Enter/Spaceでボタン操作可能
- Escでモーダル閉じる

### スクリーンリーダー対応

```html
<!-- 必須フィールドの明示 -->
<label for="email">メールアドレス <span aria-label="必須">*</span></label>

<!-- エラーの関連付け -->
<input id="email" aria-describedby="email-error" aria-invalid="true" />
<span id="email-error" role="alert">有効なメールアドレスを入力してください</span>

<!-- 進捗状況 -->
<div role="progressbar" aria-valuenow="45" aria-valuemin="0" aria-valuemax="100">
  45%達成
</div>
```

### 高齢者向け配慮

- アイコンには必ずテキストラベルを併記
- 横スワイプ不使用（縦スクロールのみ）
- 電話サポート案内を表示

```
❓ 操作方法がわからない場合
📞 0120-XXX-XXX（通話無料）
```
