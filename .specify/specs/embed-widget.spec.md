# Feature Specification: 埋め込みWidget & 寄付ページ

## Overview

WordPress等の外部サイトに埋め込み可能な寄付フォーム、およびQRコード用の独立した寄付ページ。

## URL構成

| URL | 用途 |
|-----|------|
| `/donate/:eventId` | 独立した寄付ページ（QRコード用） |
| `/embed/:eventId` | iframe埋め込み用 |
| `/qr/:eventId.png` | QRコード画像 |

## 埋め込みWidget `/embed/:eventId`

### 埋め込み方法

```html
<!-- iframe埋め込み -->
<iframe
  src="https://donate.example.com/embed/summer-2025"
  width="400"
  height="600"
  style="border: none; border-radius: 8px;"
  allow="payment"
></iframe>
```

### カスタマイズパラメータ

| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| `theme` | `light` / `dark` | `light` |
| `primaryColor` | ボタン色 | `#FF5500` |
| `bgColor` | 背景色 | `#FFFFFF` |
| `bgImage` | 背景画像URL | なし |
| `fontFamily` | フォント | `sans-serif` |
| `borderRadius` | 角丸 | `8px` |
| `hideProgress` | 進捗非表示 | `false` |
| `hideMessage` | メッセージ欄非表示 | `false` |

### 使用例

```html
<!-- ダークテーマ、カスタムカラー -->
<iframe
  src="https://donate.example.com/embed/summer-2025?theme=dark&primaryColor=%23FF0000"
  width="400"
  height="600"
></iframe>

<!-- 背景画像付き -->
<iframe
  src="https://donate.example.com/embed/summer-2025?bgImage=https%3A%2F%2Fexample.com%2Fbg.jpg"
  width="100%"
  height="700"
></iframe>
```

### コンパクトレイアウト

## QRコード `/qr/:eventId.png`

### 仕様

- 形式: PNG
- サイズ: 300x300px（デフォルト）
- 内容: `https://donate.example.com/donate/:eventId`

### パラメータ

| パラメータ | 説明 | デフォルト |
|-----------|------|-----------|
| `size` | 画像サイズ | `300` |
| `format` | `png` / `svg` | `png` |

### 使用例

```
/qr/summer-2025.png
/qr/summer-2025.png?size=500
/qr/summer-2025.svg
```

## セキュリティ

### iframe制限

```http
# レスポンスヘッダー
X-Frame-Options: ALLOW-FROM https://example.com
Content-Security-Policy: frame-ancestors 'self' https://example.com https://wordpress.example.com
```

設定で許可ドメインを指定。

### クロスオリジン

- 決済はStripe Checkoutにリダイレクト（同一オリジン問題なし）
- APIはCORSで許可ドメインのみ許可

## アクセシビリティ

- キーボード操作対応
- スクリーンリーダー対応（aria-label）
- カラーコントラスト比 4.5:1 以上
- フォーカス表示
