# Feature Specification: 管理画面

## Overview

寄付・サブスク・イベントを管理するWebベースの管理画面。

## URL

```
/admin
```

### 5.1 寄付者向けセルフサービスポータル（NEW）

FTC「Click to Cancel」規制対応。登録と同じ方法でキャンセル可能にする。

**URL**: `/my/subscriptions?token=<email_link_token>`

メール内のリンクからアクセス（認証トークン付き）。

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│   📋 マイ寄付                                               │
│                                                             │
│   ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━    │
│                                                             │
│   月額寄付                                                  │
│   ┌─────────────────────────────────────────────────────┐ │
│   │                                                     │ │
│   │   🏢 NPO法人○○                                     │ │
│   │   ¥1,000/月   次回請求: 2025年1月1日               │ │
│   │                                                     │ │
│   │   ┌──────────┐ ┌──────────┐ ┌──────────────────┐   │ │
│   │   │ 金額変更 │ │ 一時停止 │ │ キャンセルする │   │ │
│   │   └──────────┘ └──────────┘ └──────────────────┘   │ │
│   │                                                     │ │
│   └─────────────────────────────────────────────────────┘ │
│                                                             │
│   📥 寄付履歴をダウンロード（確定申告用PDF）              │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**キャンセルフロー設計原則**:
- キャンセル理由を強要しない
- 代替案（一時停止3ヶ月、減額）を提示するが強制しない
- ワンクリックでキャンセル可能
- 感謝メッセージと再開案内を表示

**理由**: 調査でキャンセル困難への不満が多数。FTC規制で「登録と同じ方法でキャンセル」が義務化。

## 管理画面アクセシビリティ（NEW）

管理者にも高齢者・視覚障害者がいる可能性を考慮。

| 項目 | 基準 |
|------|------|
| フォントサイズ | 最小14px（本文）、12px（補足） |
| コントラスト比 | 4.5:1以上 |
| タップターゲット | 最小44x44px |
